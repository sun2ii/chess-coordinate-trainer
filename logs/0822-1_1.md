# Chess Coordinate Trainer v1.1 - Development Log

## Starting Point

Extension showed coordinate overlays when pieces moved on Chess.com with quadrant-based coloring (4 colors for 4 board quadrants).

## What Evolved

### 1. ROYGBIV Color System

Replaced quadrant colors with a 64-color system encoding file and rank:

**Files (A-H) map to ROYGBIV + Pink hues:**
- A: Red (0°)
- B: Orange (30°)
- C: Yellow (60°)
- D: Green (120°)
- E: Blue (210°)
- F: Indigo (260°)
- G: Violet (290°)
- H: Pink (330°)

**Ranks (1-8) map to lightness (linear gradient):**
- Rank 1: L=0.90 (lightest/pastel)
- Rank 8: L=0.30 (darkest)

Colors generated using OKLCH color space with sRGB gamut clamping.

### 2. Overlay Modes (Q key cycles)

- **off** - no overlay
- **flanks** - queenside (red) vs kingside (blue)
- **ranks** - your half (red) vs their half (blue)
- **colors** - 64-color grid with A1, B2 labels

### 3. Exam Mode (E key toggles)

Active recall training:
- Piece moves, colored square appears (no label)
- Modal asks "square?"
- Keyboard input: `qwer`/`tyui` for files A-H, `1-8` for ranks
- Press another file key to correct mistakes
- Escape to skip
- Focus stays locked on input

Modal positioned in sidebar empty space, shows key mappings:
```
aq bw ce dr
et fy gu hi
```

### 4. UI Refinements

- Move overlay opacity reduced to 0.6 (see piece through it)
- Overlay stays 1.5s before fading
- Coordinate labels use dynamic text color based on background luminance
- Removed glow effects from labels
- Right-click disabled during exam mode

### 5. Technical Fixes

- Fixed colors overlay starting visible (now starts off)
- Added global Escape handler for exam modal
- Exam overlay persists until answered/skipped
- Input auto-refocuses if clicked away

## Files Modified

- `content.js` - main extension logic
- `styles.css` - overlay and modal styling
- `manifest.json` - version 1.1, updated description

## Key Insight

File = hue (color identity), Rank = lightness (brightness level). See a pink pastel square? That's H1. See a dark blue square? That's E7 or E8. The system makes coordinates learnable through color association.
